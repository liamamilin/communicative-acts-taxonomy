# 近邻辨析：同一句话，究竟在做什么？

这份对照用来实际查词、标例，不增设第四条分类轴。除明确链接到案例库的材料外，下列例句均为构造。先圈定要分析的一句话或一个话轮，再区分它完成的行动（P）、用到的表达操作（O）、和可观察的风格（S）。

## 先换语境：同一句话可以做不同的事

> “负责检查的人是谁？”

- **想知道人名**：说者刚接手调查，不知道分工。判为[询问信息](https://liamamilin.github.io/communicative-acts-taxonomy/#entry-P-ask-information)。此时直接回答人名是充分响应。
- **明知人名，要对方认领过错**：交接会上分工人尽皆知，漏检事实刚被确认。同一句可判为[指责](https://liamamilin.github.io/communicative-acts-taxonomy/#entry-P-blame)，问句承担[反问](https://liamamilin.github.io/communicative-acts-taxonomy/#entry-O-rhetorical-question)的操作。仅回答人名不解决说者提出的责任问题。
- **只有录下的一行字，没上下文**：保留两种读法，不因问号就判为询问，也不因语气听来强烈就判为指责。

最小观察点是**答案是否有待取得、说者是否提出了责任归属**。[案例 B04](https://liamamilin.github.io/communicative-acts-taxonomy/#case-B04) 明确设定为第一种；[案例 B01](https://liamamilin.github.io/communicative-acts-taxonomy/#case-B01) 的前文则给了第二种判据。

## 再换一个条件：指责、批评、责备、控诉、谴责

假设同一份报表漏了复核：

| 构造话语 | 关键变化 | 怎么记 |
| --- | --- | --- |
| “这份报表少了一项复核。” | 只对结果指出缺陷，没有归咎任何人 | 批评；如果只报告情况、没有评价，则也可能是告知 |
| “复核是你的职责，你却跳过了。” | 责任和规范性否定都出现 | 指责 |
| “我交给你复核，就是信你会查到底。你怎么漏了？” | 在指责上突出一个落空的关系性期待 | 可细记为责备；不能仅用亲疏或音量判定 |
| “请调查：主管删掉我的复核记录，并据此处罚我。” | 向可受理或见证的受众提出侵害主张 | 提出侵害或违规指控（控诉）；是否属实另查。若另请撤销处罚，可同时申诉 |
| “我谴责删改审核记录的做法。” | 对一项行为表明严肃的规范否定，未必识别责任人 | 不是自动指责某人。有明确对象时可与指责重叠；无对象时先记规范性批评。保留「谴责」作近邻细读，不靠强度多计一项 |

如果一句话同时评价作品和追究作者，但两者无法拆为独立动作，优先记上下文中更具体的行为；如分别要求更改作品、追究人责，则可以分别标记。见[指责研究簇](../clusters/blame.md)。

## 请求一侧：到底要谁改变什么？

围绕同一项处分：

| 构造话语 | 关键条件 | 怎么记 |
| --- | --- | --- |
| “请把处分记录给我看。” | 要看记录，不要求减免 | 一般请求；若问的是未知内容，则为询问信息 |
| “他确实违反规定，但这次能不能只警告？” | 对能处置的人提出酌情减轻；受益人是第三人 | 求情 |
| “我认罚。求你别再罚我了。” | 请求停止自己将承受或正在承受的惩罚 | 求饶，在这个情境中与本人请求宽宥重叠 |
| “我没违反这条规定，请撤销处分。” | 以事实或规则错误为理由要求复核 | 申诉复议，不自动是求情 |
| “请你帮我去跟主管说情。” | 当前听者只能转达，不能从轻 | 当前是请求代办；被请求的下一步才是代为求情 |

“恳求”重在恳切请求，“哀求”还呈现悲苦或痛切的姿态。它们可以修饰递水、求情、求饶，并不自动指定要对方完成哪件事。反过来，语气平稳也可以求情。说者若提出“我没违规；即便你仍认为违规，也请从轻”，同一个话轮可以先申诉、再提出备选的宽宥请求；分句标注比硬选一个标签更准确。见[求情研究簇](../clusters/pleading.md)及[案例 Q05](https://liamamilin.github.io/communicative-acts-taxonomy/#case-Q05)、[Q06](https://liamamilin.github.io/communicative-acts-taxonomy/#case-Q06)。

## 固定 P，再分别改变 O 和 S

场景不变：希望同事在离开前关窗。

| 构造话语 | 观察点 |
| --- | --- |
| “请把窗户关上。” | P 是请求，所求行动明说；直接不等于不礼貌 |
| “你方便的话，请把窗户关上；不方便就告诉我。” | 所求行动仍然明说；增加了拒绝空间，是更高的面子缓冲，而不是改为间接 |
| “这屋里有点冷。” | 只有双方已知关窗能解决问题、且该话轮期待行动时，才按间接请求；否则可能只是说明感受 |
| “风会把样品吹散，麻烦关窗。” | P 仍是请求；增加后果作为理由，是 O 的变化。不能仅因理由变充分，就标为更强硬 |

最后分开写下三样：**话语内容**（窗开着、请关窗）、**听者的实际响应**（关窗、拒绝或未知）、**分类证据**（哪些词和语境支持判断）。三者不是目的轴的新类别。
