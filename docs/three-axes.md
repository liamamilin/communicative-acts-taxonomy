# 三个并列目录：目的、操作、风格

P：这次交际在做什么？以可被语境支持的行为目的为入口，而不是猜测全部私人动机。指责、请求、求情等是本版候选。

O：怎样组织表达以推进该行动？例如援引事实、归因、反问、比较、承认、解释、提出替代方案、援引关系。操作可以连用；相同操作服务不同 P。它们是可组合策略，不是必须按顺序执行的步骤。

S：表达呈现怎样的风格？例如直接、委婉、克制、严厉、幽默、恳切。风格可叠加，受文化、韵律与关系影响；文本证据不够就不标。严厉不证明真实愤怒，恳切不证明主观真诚。

## 同一个案例如何跨轴
Q01 为关羽求情：P 求情/请求；O 援引关系/提出替代方案；S 委婉是暂定分析。小说叙述请求获准是结果，不是 S。
B01：P 指责/批评；O 类比/反问/归因；S 严厉只是上下文支持下的候选，不能从问号自动决定。
Q08：承认、求情与保证形成组合，当前 P 目录仅覆盖求情/请求，不把未建“承诺”词条误说成没有承诺。

## 这不是三个互斥层级
“恳求、哀求”是 P 中保留的争议词条，可能移到方式/风格；先显式标记而不是悄悄删除。“解释”在独立回合可作 P，在求情段中可作 O。需要注明分析粒度。

JSON 字段只是浏览约定。每个候选都必须能回答“用什么证据判、什么不是、是否可能跨轴”。新操作或风格先通过现有案例检验，再收进目录。没有绑定案例的候选会显示为“待补材料”，不伪装成证据充分。
