# 下一步与当前限制

本版交付可浏览的功能分组，不再用两个研究簇代替整个目的目录。广度与证据深度分开报告：目录覆盖常见交际领域，深入来源案例仍集中在指责和求情；其他条目的构造例句不冒充实录。

接下来逐组补充获得使用许可的真实现代交互材料，覆盖自己/他人、直接/中介、私下/公开、有权/无权，以及成功/拒绝/未知结果。古典和文学案例可验证文字与分析可能性，不能代表当代自然会话频率。

用双人独立标注检验边界，记录分歧而不是强迫一致。近义项若无法区分则合并，复合行为若确有独立条件则拆分。高层组可多重归属，更新时保留旧 ID 映射，避免断开案例链接。

当前不声称穷尽人类所有语言行为，不声称 ISO 兼容，不声称有统计代表性，也未完成标注者一致性测试。
