# 研究对象与边界

## 先回答能做什么
给定处境，列出可能的语言行动，说明每一种为什么算、怎样与邻近行动不同。P 暂作“完成的交际行动 / 项目”的工作简称，不把 P 等同于脑中不可见的私人目的。行为判定需要句子、上下文、参与者关系和回应共同支持。

| 层面 | 本项目问什么 | 例子 |
|---|---|---|
| 可观察材料 | 实际说了什么、在什么回合 | “望權記過，容將功贖罪” |
| 行为 P | 据材料可合理判为什么行为 | 为他人求情 |
| 目的 | 想促成什么，证据有多强 | 希望免死；不能由此断言所有隐秘动机 |
| 概念 C | 理解和执行此行为涉及哪些关系 | 过错、责任、处罚、处置者、受益人 |
| 操作 O | 怎么组织内容和推进回应 | 承认、援引旧约、提出替代处置 |
| 形式 / 风格 / 情绪 | 怎样说，是否真有证据 | 请求句、委婉；不凭文字强推真实愤怒 |
| 内容 | 命题说什么、语义角色是什么 | 谁犯何事，谁可减免何种处置 |
| 结果 | 对方实际怎样回应、制度状态是否变动 | 请求被接受或拒绝；未知就写未知 |

这些轴并非天然互斥。所谓 O 可能本身也是另一个粒度下的 P：“解释原因”在一段求情中是操作，在独立回合中也可成为主要行为。记录分析单位及层次，不追求一个词永远只属于一个栏。

同一段话可有多个行为，按片段记录组合与关系。例如“他确实违规，但请免罚，我保证监督”可分别包含承认、求情、承诺。不要把“求情失败”改标为“未求情”：行为的实施与希望造成的结果不同。制度宣告则需另外验证相应权限和程序，不能把普通人的“我宣布无罪”当有效裁决。

## 暂不做什么
建立可修订的功能分组，但不把它当作固定且穷尽的一级分类树；不承诺总数；不把情绪、反问、委婉收成 P 的平级行为；不从中文词表直接推断跨语言共性；不自动推断说话者心理；不把规范性指控当已查证事实。

将来完整表达体系可分别维护行为、操作、风格、内容等目录并建立关联。内容可按命题类型、时间关系、施事/受事/受益者等语义角色研究，而非在本仓库罗列“教育、职场、旅行”等无限话题。按所有者最新方向，本版并列建设 P 目的、O 操作、S 风格三部分，共用案例。内容暂不建目录；不意味着内容无法分类。
