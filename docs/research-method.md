# 一次研究循环

1. **选一个具体困惑**：例如“求情必须替别人说吗？”不先规定类目总数。
2. **收集可核查材料**：记录原始链接、作者/作品、章节或时间戳、访问日、相邻回合、参与者角色、再利用条件。记录材料类型：自然发生 / 文学 / 制度文本 / 构造；匿名也不能代替授权。
3. **先抄事实后作分析**：原文与改写分开；谁说、对谁、说前发生什么、之后有什么证据。缺信息记未知。
4. **独立提两个解释**：主分析、竞争分析及其证据。能识别的行为不是读取真实心理。把句段、多回合、引用嵌套说明清楚。
5. **构造最小对照**：只改变责任、权限、受益人或语境等一个因素。构造案例用于检验概念，不充当真实分布证据。
6. **两位标注者独立判断**：先用同一小批材料试标，记录分歧与理由，再协商修订。当前版本尚未完成双人复核，不报虚构一致率。
7. **修订定义与关系**：可能保留、拆分、合并或移到方式轴。记录例外，不为维护树形而删除反例。跨簇多标签是正常结果。
8. **检查再提交**：运行校验，检查隐私与来源。编号用于追踪，重命名后保留迁移说明。

## 新案例的最少记录
复制 data/cases.json 的一条作为暂时载体即可：编号、研究簇、材料类型、原文/构造句、来源（构造句明确为空）、语境、角色、暂定行为、竞争分析、COP、风格、内容、结果、把握度。字段可扩展；不要为凑字段虚构事实。提出新字段或新一级分类必须说明它解决哪条材料的困难。

## 证据分级与局限
“来源可核查”只证明文本存在，不保证分析正确。古典与小说先用于概念试验，不代表现代汉语自然会话。构造句不参与频率统计。后续优先补经许可、去标识化且有前后回合的现代真实对话；仅公开可读不等于可批量再发布。无需为了研究收集真实姓名或敏感细节。

## 分歧日志格式
日期 / 案例编号 / 原判定 / 竞争判定 / 支持证据 / 反证 / 当前处置 / 仍缺什么。争议未解决可照常收录并标“待议”。暂不使用单一分数掩盖不同种类的不确定性。
